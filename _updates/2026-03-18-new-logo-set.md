The Fresh Pops logo system is now live on the site.

This is the first complete pass at a flexible identity, something that can work across signage, print, merch, and digital without feeling overdesigned.

Designed by Stephanie at [Natives 1990](https://www.natives1990.org/about).

Current set:

- Primary logo - default mark for most uses
- Horizontal logo - for tighter layouts
- Sticker mark - simplified, more graphic
- Hero sticker - larger, more expressive version
